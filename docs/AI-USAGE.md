# AI usage disclosure

This project used Codex (OpenAI) as a coding assistant for implementation review,
debugging, test design, documentation drafting, and small refactors. Its output was
reviewed against the assignment contract, exercised locally, and revised where it did
not match the project architecture or observed behaviour.

The assistance included diagnosing the PostgreSQL enum migration failure, improving
the Ollama failure path and component tests, and drafting operational documentation.
The team remains responsible for reviewing every change and explaining the provider,
cache, Docker, Kubernetes, and CI/CD decisions at viva.

Before submission, each contributor must add any other AI tools they personally used,
identify the files or decisions those tools shaped, and state the human review or
changes made afterwards. Do not claim that an AI-produced change was written entirely
by a person, and do not list a tool that was not actually used.
